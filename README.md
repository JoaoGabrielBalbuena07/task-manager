# task-manager



\## Projeto CRUD de Gerenciador de Tarefas ##

Como executar:

\-Clone o repositório
\- Execute:

python main.py

Funcionalidades do sistema:



\-Criação de usuários

\-Criação de tarefas

\-Listagem de usuários ou tarefas

\-Alterar status e exclusão de tarefas

\-Busca de usuários



Linguagens utilizadas:



\-Python 3.14.3

\-SQLite3
